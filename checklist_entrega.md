# Checklist de entrega

- [ ] Preencher nome, disciplina e professor(a) no README.
- [ ] Criar o banco PostgreSQL e executar os cinco scripts SQL na ordem descrita.
- [ ] Instalar as dependências e abrir a aplicação localmente.
- [ ] Demonstrar no vídeo uma venda concluída, a atualização de estoque, o histórico (Function) e o relatório (View).
- [ ] Mostrar os scripts da View, Function e Procedure no vídeo e explicar o uso real de cada um.
- [ ] Criar um repositório GitHub público ou acessível ao professor.
- [ ] Enviar o código-fonte, SQL, README e link do vídeo conforme orientação da disciplina.
- [ ] Conferir se o professor consegue acessar o repositório e o vídeo.

## Publicar no GitHub pelo terminal

1. Crie um repositório vazio no GitHub, sem README/licença inicial.
2. Abra o terminal nesta pasta do projeto e execute:
   ```bash
   git init
   git add .
   git commit -m "Entrega projeto de banco de dados"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
   git push -u origin main
   ```
3. Substitua a URL pelo endereço do repositório criado e compartilhe o link com o professor.
